# SpeakerSync

SpeakerSync plays movie and music audio through **two independent Bluetooth speakers** placed in front of and behind the listener to create an immersive experience.

- **FRONT speaker**: Dialogue and small/quiet sounds (detail, foley, soft music elements).
- **BACK speaker**: Loud sounds (impacts, explosions, bass, drum hits, music peaks).
- **Latency Control**: Sample-accurate fractional delay line with manual slider trim + automatic microphone calibration.
